GuideSplit

Split and merge images privately in your browser

1 · Upload image

The file stays in your browser. Nothing is uploaded to a server.

2 · Place guides

Upload an image to begin.

Drag from the top ruler to add a vertical guide. Drag from the left ruler to add a horizontal guide. Drag a guide to reposition it. Image edges are always split boundaries.

3 · Split preview

No output areas yet.

Vertical guides split columns; horizontal guides split rows. Three vertical guides create four output images.

4 · Export

Upload an image to startPlace divider guides at the exact pixels where the image should be cut. The image edges plus your guides become the exported regions.

1 · Upload images

Select multiple images at once. New uploaded images are appended to the end unless you insert them below.

2 · Insert image

Select an image in the list, then add a file directly after it.

To put a file between two images, select the image above it and use Insert after. You can also drag any list item to a new position.

3 · Resize and reorder

Every item shows its full filename, thumbnail, and current output size. Drag an item or use arrows to set the final merge order.

4 · Merge and export
